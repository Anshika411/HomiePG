# HomiePG Marketing & Tenant Website

Public-facing portal and tenant discovery website built with Next.js 15 (App Router), React 19, and Tailwind CSS.

## Features
- **Hero & Discovery**: Search PGs by locality, room type, budget, and amenities.
- **Detailed Property Pages**: Comprehensive room previews, sharing arrangements, photo galleries, and map integration.
- **Booking & Inquiry Workflow**: Instant bed reservation, visit scheduling, and inquiry submission.
- **Owner Onboarding Pitch**: Landing pages highlighting PG owner partner benefits.

## Setup & Running

1. Copy `.env.example` to `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```
3. Visit [http://localhost:3000](http://localhost:3000).
