# HomiePG Admin Website

Platform management portal for Super Admins and Platform Managers built with Next.js 15 (App Router), React 19, and Tailwind CSS.

## Features
- **Platform Analytics**: Key metrics across PG owners, active stays, properties, and bookings.
- **Owner Verification & Moderation**: Multi-step owner approval drawer, KYC audits, and verification task queue.
- **Property Governance**: Manage building listings, rooms, beds, and amenities.
- **Tenant & Booking Management**: Oversee lease agreements, check-ins, and payments.

## Setup & Running

1. Copy `.env.example` to `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```
3. Visit [http://localhost:3001](http://localhost:3001).
